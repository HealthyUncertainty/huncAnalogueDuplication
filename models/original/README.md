# Original packages (not included)

The analysis scripts expect the five reference packages here, one folder each:

```
huncMarkovCAIS  huncMarkovCISS  huncMarkovCNRD  huncMarkovDMSS  huncMarkovNCD
```

Clone them from `https://github.com/HealthyUncertainty/<package>` into this folder, or set the
environment variable `HUNC_ORIGINAL_DIR` to wherever they live.
